# CORELCO I&D — sitio web

Sitio informativo estático de CORELCO I&D construido con HTML y CSS.

## Archivos
- `index.html`: página principal.
- `styles.css`: estilos, diseño adaptable y elementos visuales.
- `pages/terminos.html`: términos de uso y aviso informativo de privacidad.
- `styles/terminos.css`: estilos de la página legal.
- `images/logo.png`: logotipo existente del proyecto.

## Cómo probarlo
Abre `index.html` en un navegador. No requiere instalar dependencias ni ejecutar un proceso de compilación.

## Publicación
El proyecto se puede publicar en GitHub Pages, Netlify u otro alojamiento de archivos estáticos. Conserva la estructura de carpetas para que funcionen los enlaces relativos.

## Antes de publicar
- Verificar que el nombre comercial y los servicios descritos sean correctos.
- Confirmar que ambos números de WhatsApp y el enlace de Facebook sigan vigentes.
- Revisar los términos y el aviso de privacidad con base en las prácticas reales del estudio y la normativa aplicable.
- Las fuentes tipográficas se cargan desde Google Fonts; si no hay conexión, se usan fuentes alternativas locales.

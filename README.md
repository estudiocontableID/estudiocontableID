# CORELCO I&D — Sitio web

Sitio web informativo de **CORELCO I&D**, un estudio orientado a brindar servicios de contabilidad, asesoría tributaria y acompañamiento empresarial.

El proyecto presenta la identidad del estudio, sus principales servicios y sus canales de contacto mediante una interfaz moderna, adaptable y de fácil navegación.

## 🌐 Sitio web

[Visitar CORELCO I&D](https://estudiocontablecorelcoid.netlify.app/)

## ✨ Características

- Diseño moderno con identidad visual financiera y tecnológica.
- Interfaz adaptable a dispositivos móviles, tablets y computadoras.
- Secciones informativas sobre el estudio y sus servicios.
- Acceso directo al contacto mediante WhatsApp.
- Enlaces a redes sociales.
- Página de términos de uso y aviso informativo de privacidad.
- Sitio estático desarrollado con HTML y CSS.

## 🧾 Servicios

El sitio presenta información sobre los siguientes servicios:

- Contabilidad general.
- Asesoría tributaria.
- Constitución de empresas.

## 🛠️ Tecnologías utilizadas

- HTML5 — estructura y contenido.
- CSS3 — diseño, estilos y adaptación visual.
- Netlify — publicación y alojamiento del sitio web.
- Git y GitHub — control de versiones y gestión del código.

## 📦 Publicación

El sitio está publicado mediante Netlify.
